# Zoggon 2026

Remake strzelanki **Zoggon** z Commodore 64 (Gundolf Kiefer, Magic Disk 64, 11/1989) w przeglądarce, z możliwością instalacji na Androidzie.

- 8 sektorów, na końcu boss Zoggon
- paliwo uzupełniasz, trafiając w zbiorniki FUEL
- sterowanie: lewy kciuk – drążek, prawy – OGIEŃ i BOMBA; na klawiaturze strzałki/WSAD, Z/spacja, X, P (pauza), M (muzyka)

## Instalacja na Androidzie
Otwórz stronę gry w Chrome → menu ⋮ → **Dodaj do ekranu głównego** / **Zainstaluj aplikację**.

## Rozwój
Czysty HTML + moduły JS, bez budowania. Testy: `node --test`.
