# Zoggon 2026 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Grywalny remake Zoggona (C64, 1989) w przeglądarce, instalowany na Androidzie jako PWA.

**Architecture:** Statyczna strona bez kroku budowania: `index.html` + moduły ES w `js/`. Logika gry (teren, kolizje, stan, sektory) w czystych modułach bez DOM, testowanych `node --test`; rysowanie (Canvas 2D), dźwięk (WebAudio) i wejście (dotyk/klawiatura) w osobnych modułach. Pętla stałokrokowa 60 Hz.

**Tech Stack:** HTML5 Canvas 2D, WebAudio, ES modules, Service Worker + Web App Manifest, testy `node:test` (Node 22).

**Spec:** `claude/zoggon-2026-projekt.md` (dokument projektu)

## Global Constraints
- Ekran poziomy, logiczna rozdzielczość 960×540 skalowana do ekranu (letterbox).
- Brak zewnętrznych zasobów i bibliotek: grafika i dźwięk generowane kodem.
- 60 kl./s na przeciętnym telefonie z Androidem; budżet cząsteczek ≤ 400.
- 8 sektorów po ~120 s, sektor 8 kończy boss.
- 3 życia; +1 życie co 10 000 pkt; po śmierci restart od początku sektora.
- Paliwo maleje z czasem; trafienie zbiornika (pocisk lub bomba) dodaje paliwo; paliwo 0 → statek spada.
- Sterowanie: lewa połowa ekranu – drążek; prawa – OGIEŃ (przytrzymanie = seria) i BOMBA. Klawiatura: strzałki/WSAD, Z/spacja ogień, X bomba, P pauza.
- Rekord zapisywany lokalnie (localStorage w try/catch).
- Gra działa offline po pierwszym uruchomieniu.

## Review Focus
1. Obrót telefonu do pionu → gra pauzuje i pokazuje „Obróć telefon”, nie rozjeżdża się. (Task 6)
2. Przejście aplikacji w tło / zgaszenie ekranu → automatyczna pauza, brak „skoku” czasu po powrocie (dt przycięte do 100 ms). (Task 6)
3. Dwa palce naraz (drążek + ogień) → oba działają niezależnie (śledzenie po `pointerId`). (Task 4)
4. Brak localStorage (tryb prywatny) → gra działa, rekord tylko w pamięci. (Task 3)
5. Dźwięk zablokowany do pierwszego dotknięcia → AudioContext wznawiany przy pierwszym geście, brak błędu. (Task 5)
